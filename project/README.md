# Project records

This directory contains Wake's development records: decisions, proposals,
plans, reports, handoffs, acceptance evidence, and historical designs. Some
describe proposed or superseded behavior. Consult [Wake documentation](../docs/README.md),
the current contracts, and source code for the system as it exists today.

The `superpowers/` directory holds Superpowers design specifications and
implementation plans. The `architecture/` directory includes the functional
decision catalogue and evidence used by repository checks.
